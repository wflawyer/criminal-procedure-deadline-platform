# 刑事诉讼程序与期限管理平台

面向中国刑事诉讼全流程的案件节点管理工具，同时提供网页平台和可独立安装的 Codex Skill。当前仓库已经具备本地运行、离线案件文件计算和 GitHub 分发所需的基本结构；公开仓库、许可证和线上部署地址仍需仓库所有者确认。

## 当前能力

- 覆盖接报案、刑事立案、检察立案监督、强制措施、审查起诉、一审、二审、申诉再审和执行；
- 支持被害人／诉讼代理人、犯罪嫌疑人／被告人、辩护人三类视角；
- 区分机关办案期限、当事人申请期限、羁押期限和监督触发点；
- 每个计算节点同时显示法律依据、法条原文、计算说明和当前角色行动；
- 内置 15 份刑事法律、司法解释、规章和专题规范性文件，可站内全文搜索；
- 支持多案件管理、本地自动保存、JSON 导入导出、日期倒置和程序分支冲突检查；
- 完整内置 2026 年法定节假日和调休。非羁押程序期限末日遇休假日顺延，羁押期限不顺延。

## 两种使用方式

### 1. 网页平台

网页平台适合多案件台账、可视化时间线和浏览器内自动保存。克隆仓库后运行：

```bash
npm ci
npm run dev
```

朋友通过网页链接直接使用的前提是另行部署本项目。GitHub 仓库链接只是源代码地址，不会自动成为可访问的网站。

### 2. Codex Skill

仓库内的独立 Skill 位于 [`codex-skill/calculate-criminal-deadlines`](codex-skill/calculate-criminal-deadlines)。克隆仓库后安装：

```bash
bash scripts/install_codex_skill.sh
```

如果本机已经存在同名 Skill，安装器默认停止，不会覆盖。确认更新时使用：

```bash
bash scripts/install_codex_skill.sh --force
```

安装后在新的 Codex 任务中输入：

```text
使用 $calculate-criminal-deadlines，根据我的脱敏案件节点计算期限，并从被害人代理人视角生成行动报告。
```

GitHub 仓库公开后，也可以让 Codex 的 `$skill-installer` 直接从仓库内上述 Skill 路径安装。

## 数据边界

- 新用户首次打开只看到通用空白刑事案件，不包含真实当事人或个案材料。
- 案件数据默认只存在当前浏览器的 `localStorage`，服务器不保存案件库。
- 分享网页链接不会分享案件数据。协作评审需要另行发送脱敏后的 JSON，或让对方自行录入测试数据。
- Skill CLI 只读取用户指定的本地 JSON，并将报告写到本地路径；但把真实案情粘贴进 Codex 对话并不等于纯离线处理，应优先使用脱敏节点。
- 为兼容此前已录入的数据，浏览器存储键暂时保持不变；旧行政字段在读取时被忽略，已有刑事日期和案件名称继续保留。

## 法律数据维护

`scripts/build_legal_corpus.py` 从记录的来源重新抓取文本，检查关键条文锚点、最小字符数并计算 SHA-256。生成物位于 `public/legal/`。任何期限规则修改都应同步完成：法源核验、规则引擎修改、原文展示和自动化测试。

## 开源发布状态

GitHub 发布前仍需确定仓库名称、公开或私有、开源许可证和网页部署渠道。具体清单位于 [`docs/OPEN_SOURCE_CHECKLIST.md`](docs/OPEN_SOURCE_CHECKLIST.md)。在许可证确定前，源代码即使上传到公开仓库，也不等于已授予他人复制、修改和再发布的开源许可。

现有本地 Git 历史曾包含真实案件姓名，不能直接把当前 `main` 的全部历史推送到公开仓库。公开发布应从已脱敏的当前文件快照建立全新的首个提交，或者在完整审计后重写历史。
